# Codes d'erreur

**E101 - Accès caméra refusé** : autorisez la caméra dans les réglages du téléphone > Applications > PanelConso Scan > Autorisations.

**E204 - Code-barres non lu** : nettoyez l'objectif, améliorez l'éclairage ou saisissez le code manuellement.

**E302 - Échec de synchronisation** : vérifiez votre connexion puis lancez Menu > Paramètres > Synchroniser maintenant. Les saisies restent sur le téléphone : ne désinstallez pas l'application.

**E401 - Session expirée** : reconnectez-vous. Vos saisies en attente sont conservées.

**E500 - Erreur serveur** : le problème vient de nos serveurs, réessayez plus tard. Si l'erreur persiste plus de 24 heures, contactez le support en indiquant le code d'erreur et une capture d'écran.

## Plantages répétés ou autre code
Sur Android, videz le cache de l'application (Réglages > Stockage > Vider le cache), mais n'utilisez pas « Effacer les données ». Si le problème persiste, contactez le support en précisant le modèle du téléphone et la version de l'application (Menu > À propos).
