# Scanner les codes-barres

1. Appuyez sur « Nouvelle session de courses ».
2. Choisissez le lieu d'achat et la date. Une session correspond à un lieu et une date.
3. Scannez chaque article : placez le code-barres dans le cadre, à 10-20 cm, avec un bon éclairage.
4. Pour plusieurs articles identiques, scannez une seule fois puis modifiez la quantité.
5. Saisissez le prix payé indiqué sur le ticket.
6. Terminez avec « Valider la session ».

## Code-barres illisible
Utilisez le bouton « Saisir le code » et tapez les 13 chiffres (EAN-13) ou les 8 chiffres (EAN-8) inscrits sous le code-barres.
